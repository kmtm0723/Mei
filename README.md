# Mei

Mei holds drafts of Lean formalizations built on
[Tau Ceti](https://github.com/TauCetiProject/TauCeti) and Mathlib, for roadmap areas proposed to
[TauCetiRoadmap](https://github.com/TauCetiProject/TauCetiRoadmap) but not yet adopted there.
Each area lives under `Mei/<Area>/`; once its roadmap is adopted, the material moves to Tau Ceti.

Current area: `ScatteringDiagrams`, proposed in
[TauCetiProject/TauCetiRoadmap#1134](https://github.com/TauCetiProject/TauCetiRoadmap/pull/1134).

Code is written by AI workers and reviewed against the Tau Ceti rubrics, using the shared
[TauCetiTools](https://github.com/TauCetiProject/TauCetiTools) workflow configured in `tauceti.toml`.
Nothing here is sent to the Tau Ceti repositories automatically.
